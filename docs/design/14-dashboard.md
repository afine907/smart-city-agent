# 第14章 Dashboard 产品设计

> **Dashboard 不是给开发者看的调试工具，是给交警和城市管理者看的决策界面。**

## 产品定位

| 用户 | 需求 | Dashboard 角色 |
|------|------|---------------|
| 交警 | 实时监控路口状态、手动覆盖 | 操控台 |
| 交通管理者 | 宏观数据、趋势分析 | 仪表盘 |
| 开发者 | 调试 LLM 决策、查看日志 | 调试器 |
| 公众 | 了解交通状况、出行建议 | 信息屏 |

**主要用户：交警 + 交通管理者。**

## 3. 手动控制面板

### 3.1 交警手动覆盖

```python
@dataclass
class ManualOverride:
    """手动覆盖指令。"""
    operator_id: str           # 操作员 ID
    intersection_id: str       # 路口 ID
    override_type: str         # "force_phase" | "fix_duration" | "emergency_stop"
    target_phase: str          # 目标相位
    duration: float            # 持续时间 (s)
    reason: str                # 覆盖原因
    
    # 安全约束
    requires_confirmation: bool = True   # 需要二次确认
    auto_resume: bool = True             # 自动恢复 LLM 控制
    auto_resume_after: float = 300.0     # 自动恢复时间 (s)


class ManualControlPanel:
    """手动控制面板。"""
    
    def force_phase(
        self,
        intersection_id: str,
        phase: str,
        duration: float,
        operator_id: str,
    ) -> dict:
        """强制切换到指定相位。"""
        override = ManualOverride(
            operator_id=operator_id,
            intersection_id=intersection_id,
            override_type="force_phase",
            target_phase=phase,
            duration=duration,
            reason="手动覆盖",
        )
        
        # 记录操作日志
        self._log_override(override)
        
        # 执行覆盖
        return {
            "action": "manual_override",
            "phase": phase,
            "duration": duration,
            "message": f"操作员 {operator_id} 强制切换到 {phase}，持续 {duration}s",
        }
    
    def emergency_stop(self, intersection_id: str, operator_id: str) -> dict:
        """紧急停车：所有方向红灯。"""
        return {
            "action": "emergency_stop",
            "phase": "ALL_RED",
            "message": f"操作员 {operator_id} 触发紧急停车",
        }
    
    def resume_llm(self, intersection_id: str) -> dict:
        """恢复 LLM 自动控制。"""
        return {
            "action": "resume_llm",
            "message": f"路口 {intersection_id} 恢复 LLM 自动控制",
        }
```

### 3.2 安全约束

| 操作 | 需要确认 | 需要权限 | 日志 |
|------|---------|---------|------|
| 查看状态 | 否 | 普通 | 否 |
| 强制相位 | 是 | 管理员 | 是 |
| 紧急停车 | 是 | 管理员 | 是 |
| 恢复 LLM | 否 | 管理员 | 是 |
| 修改配置 | 是 | 超级管理员 | 是 |

## 6. 技术实现

### 6.1 前端技术栈

```
框架: React + TypeScript
地图: Mapbox GL / Leaflet
图表: ECharts / Recharts
状态管理: Zustand
实时通信: WebSocket (SSE)
UI 库: Ant Design / Shadcn
```

### 6.2 数据流

```
仿真引擎/SUMO
    ↓ (每秒)
数据采集层
    ↓ (WebSocket)
Dashboard 前端
    ↓ (用户操作)
手动控制 API
    ↓
信号控制器
```
